읽고, 찾고, 기록하는 방법을 실제 버튼 순서대로 안내합니다. 성경 본문과 개인 기록은 준비된 판본에서 인터넷 연결 없이도 사용할 수 있습니다.

처음 열었다면

  1. 화면 아래의 읽기를 누릅니다.
  2. 위쪽의 현재 권·장을 누르고 읽을 본문을 고릅니다.
  3. 기록하고 싶은 절을 한 번 누르면 구절 도구가 열립니다.

성경 읽기와 권·장 이동

  1. 아래 탭에서 읽기를 누릅니다.
  2. 상단 가운데의 현재 권·장을 누르면 권·장 이동이 열립니다.
  3. 최근·구약·신약에서 고르거나 요 3:16처럼 주소를 입력하면 해당 본문이 열립니다.
  4. 읽기 방식을 세로 스크롤로 고르면 위·아래로, 좌우 넘김으로 고르면 좌·우로 이동합니다.

경로: 읽기 → 상단 현재 권·장

구절 복사·공유·기록

  1. 읽기 화면에서 원하는 절을 한 번 누릅니다.
  2. 아래에 나타난 구절 도구에서 복사·공유·북마크·메모·형광펜 중 하나를 누릅니다.
  3. 메모를 작성하고 닫으면 저장되며, 형광펜은 색을 고른 뒤 선택 표시를 확인합니다.
  4. 저장한 항목은 아래의 보관함에서 원문과 함께 다시 볼 수 있습니다.

경로: 읽기 → 절 누르기 → 아래 구절 도구

단어·문장·성경 주소 찾기

  1. 아래 탭에서 찾기를 누릅니다.
  2. 검색창에 단어, 문장 일부 또는 창 1:1과 같은 성경 주소를 입력합니다.
  3. 결과에서 원하는 구절을 누르면 읽기 화면의 정확한 절로 이동합니다.

경로: 아래 찾기 → 검색어 입력 → 결과 누르기

읽기표로 진도 관리

  1. 아래 탭에서 읽기표를 누릅니다.
  2. 상단의 계획 이름을 누르고 읽기 계획과 시작일을 고릅니다.
  3. 읽을 본문의 글자 행을 누르면 해당 본문이 열립니다.
  4. 읽은 뒤에는 왼쪽의 체크박스를 누릅니다. 잘못 표시했다면 저장 안내에서 되돌리기를 누릅니다.

경로: 아래 읽기표 → 계획 선택 → 글자 행 또는 체크박스

보관함과 백업·복원

  1. 아래 탭에서 보관함을 누릅니다.
  2. 북마크·메모·형광펜 탭을 눌러 저장한 기록을 보고, 항목을 누르면 원문으로 이동합니다.
  3. 백업하기를 누르면 시스템 공유 화면이 열립니다. JSON 파일을 믿을 수 있는 파일 저장소에 보관하세요.
  4. 복원을 누르고 이전에 내보낸 JSON 파일을 고릅니다. 확인 화면에서 기록 수를 확인한 뒤 복원합니다.

중요: 복원은 현재 기록을 백업 파일의 기록으로 교체합니다. 먼저 현재 기록을 백업하세요. 백업은 암호화되지 않은 평문 JSON이며 자동 클라우드 동기화는 아닙니다.

읽기 환경과 언어·판본

눈에 맞게 읽기

  1. 읽기 화면 오른쪽 위의 가를 누릅니다.
  2. 글자 크기·줄 간격·본문 폭을 조정하고, 세로 스크롤과 좌우 넘김 중 편한 방식을 고릅니다.
  3. 밝게·눈 편안·어둡게와 화면 꺼짐 방지를 필요한 때만 선택합니다.
  4. 전체 설정을 한 번에 바꾸려면 왼쪽 위 메뉴 → 읽기 모드에서 기본 읽기, 처음 읽기, 목회·연구, 큰글·간편 중 하나를 고릅니다. 오른쪽 위의 '가'를 눌러 각 설정을 다시 조정할 수 있습니다.

성경 언어와 앱 표시 언어

  1. 읽기 화면 왼쪽 위의 메뉴를 누릅니다.
  2. 언어 및 판본을 누릅니다.
  3. 읽을 성경 언어·판본과 앱 메뉴 언어를 각각 고릅니다. 현재 빌드에 준비된 판본만 목록에 표시됩니다.

경로: 읽기 → 오른쪽 위 '가' / 읽기 → 왼쪽 위 메뉴 → 읽기 모드 또는 언어 및 판본

큰 글자·접근성·오프라인

  • 큰글·간편 설정은 글자와 읽기 조작계를 함께 크게 보여 줍니다. 기기의 글자 크기 설정도 함께 반영됩니다.
  • 눈 편안과 어둡게를 읽는 환경에 맞게 고르세요.
  • 버튼은 VoiceOver와 TalkBack에서 기능 이름으로 읽힐 수 있도록 구성되어 있습니다.
  • 준비된 성경 본문, 검색, 보관함, 읽기표는 오프라인으로 사용할 수 있습니다.

문제 해결

메모나 기록이 저장되지 않아요.

저장 안내 문구를 확인하고 앱을 다시 열어 보세요. 기기의 저장 공간을 확인하고, 앱을 삭제하기 전에 보관함의 기존 기록을 백업하세요.

복원 파일을 열 수 없어요.

Ribbon Bible에서 내보낸 JSON 파일인지, 16MiB보다 작은지 확인하세요. 더 최신 버전에서 만든 백업이라면 앱을 업데이트한 뒤 다시 시도하세요. 복원이 실패해도 기존 기록은 그대로 유지됩니다.

새 기기에서 구매한 앱과 기록을 이어서 쓰고 싶어요.

같은 Apple 또는 Google 스토어 계정의 구입 항목에서 앱을 다시 내려받으세요. 개인 기록은 구매 내역과 별도이므로, 이전 기기에서 내보낸 백업 파일을 새 기기의 보관함에서 복원해야 합니다.

원하는 언어나 판본이 보이지 않아요.

읽기 화면의 메뉴 → 언어 및 판본에서 확인하세요. 권리와 품질 기준을 통과해 현재 빌드에 포함된 판본만 표시됩니다.

검색 결과가 없어요.

긴 문장 대신 핵심 단어 몇 개로 다시 검색하거나, 성경 주소는 요 3:16처럼 권명·장·절 순서로 입력하세요.
